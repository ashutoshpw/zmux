# App icon provenance

`AppIcon.png` was generated for zmux using the built-in OpenAI image generation tool
on 2026-10-14. It does not reuse cmux artwork. The generated asset is distributed
with this repository under its MIT license.

Prompt: Original macOS developer terminal workspace Dock icon; dark graphite rounded
square, large crisp ivory geometric z suggesting multiplexed terminal panes, restrained
cyan terminal accents, subtle bevel, readable at small sizes, front-facing, no wordmark,
no existing terminal brand marks. One square production app asset.

The macOS build uses Apple's `sips` and `iconutil` to produce the required icon sizes.
